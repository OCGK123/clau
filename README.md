# 클로 (Clau)

앱 창 한쪽에 사는 작은 친구입니다. 선택한 앱을 따라다니고, 얼굴이나 몸을 누르면 Claude Code, Codex, Groq 중 정해 둔 순서대로 물어 대답합니다. 머리를 쓰다듬으면 X자 눈과 하트로 반응하고, 집어서 옮기면 손의 움직임에 따라 달랑거립니다.

## 설치

### 설치 도우미 (파일 하나, 창으로)

[릴리스](https://github.com/OCGK123/clau/releases/latest)에서 내 컴퓨터용 파일 하나를 받아 여세요. 설치, 업데이트, 고치기(다시 설치), 삭제, 열기를 모두 이 창에서 합니다.

| 운영체제 | 파일 | 여는 법 |
|---|---|---|
| Windows | `Clau-Installer-Windows.cmd` | 더블클릭 (SmartScreen이 막으면 **추가 정보 → 실행**) |
| macOS | `Clau-Installer-macOS.command` | 우클릭 → **열기** |
| Linux | `Clau-Installer-Linux.sh` | 파일 관리자에서 실행, 또는 `sh Clau-Installer-Linux.sh` |

받은 파일은 릴리스에 올라온 sha256과 맞는지 확인한 뒤에만 설치합니다. 지울 때는 설정까지 지울지 묻고, Claude Code 연결과 자동 실행도 함께 거둡니다. 관리자 권한은 필요 없습니다.

### 한 줄 설치 (터미널)

터미널에 한 줄 붙여 넣으면 이 컴퓨터에 맞는 최신 버전을 받아 설치하고 켭니다. 이미 깔려 있으면 새 버전으로 바꾸고, 설정은 그대로 둡니다.

**Linux, macOS**

```bash
curl -fsSL https://raw.githubusercontent.com/OCGK123/clau/main/install.sh | sh
```

**Windows** (PowerShell)

```powershell
irm https://raw.githubusercontent.com/OCGK123/clau/main/install.ps1 | iex
```

받은 파일은 릴리스에 올라온 sha256과 맞는지 확인한 뒤에만 설치합니다. 관리자 권한은 필요 없습니다.

직접 받으려면 [릴리스](https://github.com/OCGK123/clau/releases/latest)에서 zip을 받아 풀고 안의 설치 파일을 실행하세요.

| 운영체제 | 실행할 것 | 설치되는 곳 |
|---|---|---|
| Linux | `sh install.sh` | `~/.local/share/clau`, 앱 메뉴의 **클로**, 터미널 명령 `clau` |
| Windows | `install.cmd` 더블클릭 | `%LOCALAPPDATA%\Clau`, 시작 메뉴의 **Clau** |
| macOS | `Install.command` 우클릭 → 열기 | 응용 프로그램 폴더의 **Clau** |

서명이 없는 앱이라 zip으로 받으면 Windows는 SmartScreen의 **추가 정보 → 실행**, macOS는 처음 한 번 **우클릭 → 열기**가 필요할 수 있습니다(한 줄 설치는 이 과정이 없습니다). Linux에서 지울 때는 `sh uninstall.sh`를 실행하세요.

## 업데이트

클로가 켜져 있으면 가끔 GitHub 릴리스를 살펴보고, 새 버전이 나오면 한 번 알려 줍니다. 알림을 누르거나 설정 → 실행 → 업데이트의 **지금 업데이트**를 누르면 받아서 바꾼 뒤 다시 켜집니다. 오른쪽 클릭 메뉴에도 업데이트 항목이 생깁니다. 터미널에서는 `clau --update`.

받은 파일은 sha256을 맞춰 본 뒤 설치 폴더 옆에 풀고, 클로가 꺼지는 순간 폴더째 바꿔 넣습니다. 중간에 실패하면 원래 버전이 그대로 남습니다. 설치 폴더에 쓸 권한이 없으면 릴리스 페이지를 열어 줍니다. 알림이 필요 없으면 **새 버전이 나오면 알려 주기**를 끄세요.

## 켜기와 설정

- 앱 메뉴 또는 시작 메뉴에서 **클로** 실행
- Linux 터미널에서 `clau`
- Claude Code 연동을 연결한 뒤 `/clau`
- 설정 → 실행에서 **컴퓨터를 켤 때**, **Claude Code를 열 때** 자동 실행 선택

클로를 오른쪽 클릭하고 **설정…**을 누르면 설정 창이 열립니다. 바꾼 설정은 바로 적용되고 다음 실행에도 유지됩니다. 이미 실행 중일 때 클로를 한 번 더 실행해도 설정 창이 열립니다.

## 대화하기: 대답해 줄 곳과 순서

설정 → 대화의 **대답해 줄 곳**은 순서 목록입니다. 위에서부터 차례로 묻고, 앞의 서비스가 한도를 다 썼거나 로그인·연결 문제로 막히면 같은 질문과 대화 기억을 다음 서비스로 넘깁니다.

- **순서 바꾸기**: 칸을 잡고 위아래로 끌거나, 칸 오른쪽의 화살표를 누릅니다. 키보드로는 이름에서 Alt+↑/↓.
- **쓸지 말지**: 칸마다 스위치. 꺼 둔 곳은 건너뜁니다. 하나는 언제나 켜져 있어야 합니다.
- **그 서비스의 설정**: 이름을 누르면 칸 아래에 모델, 실행 파일, API 키가 펼쳐집니다.

| 서비스 | 준비 | 모델 |
|---|---|---|
| Claude Code | `claude` 명령을 설치하고 로그인 | Haiku·Sonnet·Opus·Fable 중에서, 또는 모델 ID 직접 적기 |
| Codex | 최신 Codex CLI를 설치하고 `codex login` | 로그인한 계정에서 쓸 수 있는 모델 목록(Codex가 받아 둔 목록을 읽음) |
| Groq | API 키를 넣고 **저장** | 키로 받아 온 계정의 대화 모델 목록. 키가 없으면 잘 알려진 몇 개 |

모델 목록이 바뀌었으면 **모델 목록 다시 받기**를 누르세요. 칸마다 지금 고른 모델이 보이고, 쓸 수 없는 상태(명령을 못 찾음, 키 없음)면 그 까닭이 빨갛게 보입니다.

실행 파일은 자동으로 찾습니다. 찾지 못하면 그 서비스 칸을 눌러 **실행 파일** 경로를 지정하세요. Windows의 공식 npm 설치도 지원합니다. 직접 만든 `.cmd` 또는 `.bat` 래퍼 대신 공식 CLI나 실행 파일을 지정하세요.

Codex 연결은 **Codex CLI 0.155.1**의 명령 형식을 기준으로 확인했습니다. `exec --json`, `--ephemeral`, `--ignore-user-config`, `--ignore-rules`를 지원하는 최신 CLI가 필요합니다. 클로는 대화 전용 실행에서 사용자 `config.toml`을 불러오지 않으므로, 빈 모델 입력은 사용자 설정에 저장된 모델 대신 Codex 기본 모델을 뜻합니다. CLI 설치와 로그인은 [공식 Codex CLI 안내](https://learn.chatgpt.com/docs/codex/cli), 실행 방식은 [공식 비대화형 실행 문서](https://learn.chatgpt.com/docs/non-interactive-mode)를 참고하세요.

얼굴이나 몸을 눌러 말풍선을 열고 Enter로 보내세요. 답을 받는 중에는 **멈추기**로 중지할 수 있습니다. 캐릭터를 다시 누르거나 Esc를 누르면 말풍선을 닫습니다. 설정 → 대화에서는 말투와 성격, 이모지 사용, 기억할 대화 수, 말풍선 닫는 시간을 바꿀 수 있습니다. 기억하는 대화를 0으로 설정하면 지난 대화를 붙이지 않습니다.

말풍선은 별도 투명 창에 뜹니다. 열 때는 꼬리 끝(클로의 머리)에서 작은 방울로 시작해 젤리처럼 퐁 부풀어 자리 잡고(460ms), 닫을 때는 살짝 부풀었다가 꼬리 끝으로 쏙 들어갑니다(240ms). 글자는 상자가 거의 다 부푼 뒤에 나타납니다. 디자인은 Claude 데스크톱처럼 아이보리 종이와 얇은 선이며, 운영체제가 다크 모드면 어두운 색으로 바뀝니다. 대화를 열거나 보내도 캐릭터 창의 크기와 위치는 바뀌지 않습니다. 화면 위쪽에 공간이 부족하면 말풍선을 아래에 표시하고, 화면 가장자리에서는 말풍선만 안쪽으로 맞춥니다.

대답은 한 글자씩 나타납니다. 말풍선이 열린 채로 캐릭터를 누르면(머리 포함) 말풍선이 닫힙니다. 생각하는 동안에는 클로의 머리 위에 로딩 표시가 돕니다.

**눌러서 대화**를 끄면 진행 중인 응답이 중지되고 말풍선이 닫힙니다. 쓰다듬기와 자리 옮기기는 설정 → 반응에서 따로 켜고 끌 수 있습니다. 맨 위 서비스를 바꾸면 이전 대화 기억을 비웁니다.

## 따라다닐 앱 고르기

설정 → 자리에서 **선택한 앱 창 안**을 고른 뒤 **따라붙을 앱** 목록에서 선택하세요. 목록에는 지금 창이 열려 있는 앱이 표시됩니다. 새로 실행한 앱이 없다면 **새로고침**을 누르세요.

앱 이름을 문자열로 직접 적을 필요가 없습니다. 클로는 선택한 앱의 식별자를 저장하므로 앱이나 클로를 다시 실행해도 같은 앱을 찾습니다. 선택했던 앱이 꺼져 있어도 선택은 유지되고, 다시 열리면 따라붙습니다. 일시적인 프로세스 번호나 창 번호는 저장하지 않습니다.

| 사는 곳 | 보이는 때 |
|---|---|
| 선택한 앱 창 안 | **선택한 앱을 쓰는 동안만** 또는 **선택한 앱이 열려 있으면 계속** |
| 화면 위 | 항상 표시. **항상 다른 창 위에**를 따로 선택 가능 |

Windows, macOS, Linux KDE와 X11용 창 추적 코드가 포함되어 있습니다. macOS에서는 운영체제가 요청하는 손쉬운 사용 권한이 필요할 수 있습니다. 다른 Wayland 환경(GNOME 등)은 앱 창 목록과 위치를 제공하지 않아 **화면 위** 모드를 사용해야 합니다. 선택한 앱의 실행 파일이나 창 클래스가 업데이트로 바뀌었다면 목록에서 다시 선택하세요.

## 손길에 반응하기

| 동작 | 반응 |
|---|---|
| 얼굴이나 몸 누르기 | 말풍선 열기·닫기 |
| 모자나 정수리 누르기·문지르기 | X자 눈, 눌렸다 돌아오는 몸, 누른 자리의 반짝이와 하트. 연타하면 칠 때마다 말랑 동작이 처음부터 다시 시작하고 더 깊게 눌림 |
| 몸을 잡아 끌기 | X자 눈으로 집어 든 지점에 매달림. 좌우로 빠르게 움직일수록 더 흔들리고 멈추면 서서히 잦아듦 |
| 손 놓기 | 자연스럽게 제자리로 돌아오고 새 위치를 기억 |
| 오른쪽 클릭 | 설정, 고정 모드, 자리, 크기 등 메뉴 |
| 마우스 움직이기 | 눈이 마우스 쪽을 바라봄(설정 → 반응 → **마우스 따라보기**) |
| 머리를 연달아 오래 쓰다듬기 | 볼이 빨개지며 몸을 배배 꼼(부끄) |
| 머리를 빠르게 문지르기 | 간지러워서 킥킥 |
| 세게 흔들다 내려놓기 | 눈이 X가 되고 머리 위로 반짝이가 빙글빙글(어질어질) |
| 머리에 손 올리기 | 쓰다듬어 줄 줄 알고 살짝 움찔 |

혼자 있을 때도 반응합니다. 한동안 조용하면 하품을 한 번 하고 졸고, 깨면 기지개를 켭니다. 2분 넘게 숨어 있다가 다시 나타나면 폴짝 뛰며 반기고, Claude Code가 부르면 깜짝 놀라 머리 위에 느낌표가 뜹니다.

가만히 있을 때는 세로로 숨을 쉬듯 늘었다 줄었다 하고, 작은 친구도 같은 박자로 말랑하게 따라 합니다. 얼굴(눈, 입, 앞머리, 볼)은 몸보다 살짝 늦게 따라와서, 폴짝 뛰고 내려앉을 때 꾹 눌렸다가 튕겨 오릅니다. 생각·말하기·웃음·쓰다듬기처럼 상태가 바뀔 때는 지금 모습에서 새 동작으로 끊김 없이 이어지며 한 번 꿀렁합니다. 대답을 마치고 웃을 때는 머리 둘레로 반짝이가 퍼집니다. 눈은 눈꺼풀이 위에서 내려와 덮었다가 걷히는 방식으로 깜빡입니다.

흔들림은 반복 애니메이션 대신 마우스 이동에 반응하는 감쇠 운동으로 계산합니다. 설정 → 반응에서 **집어서 자리 옮기기**와 **움직임에 따라 흔들리기**를 각각 끌 수 있습니다. 설정 → 모습의 **움직임 줄이기**를 켜면 몸의 움직임을 줄이고 표정으로 반응합니다.

크기, 보이는 범위, 작은 친구 표시, 불투명도, 좌우 뒤집기도 설정 → 모습에서 바꿀 수 있습니다. 붙은 창 안에서 옮긴 자리는 가까운 모서리 기준으로 기억합니다.

**보이는 범위**는 전신, 자동, 상반신 중에서 고릅니다. **자동**은 바닥(붙은 앱 창의 아래 끝, 화면 위 모드면 화면 아래 끝)에 내려놓으면 상반신으로 앉고, 들어 올리면 전신이 됩니다. 끌어서 바닥에 대면 몸이 바닥 밑으로 들어가며 가려지고, 놓으면 상반신 자리까지 미끄러져 앉습니다. 전신과 상반신의 그림 크기는 똑같고, 아래만 바닥에 가려집니다. 창 크기도 바뀌지 않아 오갈 때 깜빡이지 않습니다.

## 효과음

설정 → 반응 → 효과음에서 정합니다. 기본 소리는 모두 앱에 들어 있는 녹음 파일입니다.

- **쓰다듬을 때**: 꺅(기본) / 직접 고른 파일 / 소리 없음. 연타하면 앞의 소리를 끊지 않고 겹쳐서 납니다.
- **말할 때**: 톡톡(기본) / 직접 고른 파일 / 소리 없음. 대답이 한 글자씩 나타나며 글자마다 한 번씩 나고, 빠르게 이어지면 겹칩니다.
- **채팅 효과음**: 말풍선을 열고 닫을 때, 질문을 보낼 때, 대답이 나타날 때, 대답을 마치고 신날 때.
- **효과음 켜기**와 **소리 크기**가 전체를 다스리고, 각 항목의 **듣기**로 미리 들을 수 있습니다.

직접 고른 파일(WAV, MP3, OGG, M4A, FLAC, WebM, 10MB 이하)은 클로 안에 복사해 두므로 원래 파일을 옮겨도 계속 납니다. 소리 끝에 붙은 긴 무음은 재생하지 않습니다.

## 백그라운드 동작과 배터리

움직임은 하나의 공용 루프에서 그립니다. 숨쉬기·둥실거림처럼 느린 움직임은 1초에 20번, 보통 움직임은 24번, 폴짝·말랑처럼 빠른 움직임은 화면 주기에 맞춥니다. 배터리에서는 느린·보통 움직임을 12번, 빠른 몸짓을 최대 30번으로 줄이되 숨쉬기·둥실거림·입 움직임은 유지합니다. 눈에 띄지 않을 만큼 바뀐 프레임의 화면 수정은 건너뜁니다.

클로가 숨겨지면 눈 깜빡임, 입 움직임, 물리 계산, 효과음을 모두 쉬고, 다시 보일 때 지금 상태에 맞춰 이어 갑니다. 따라붙을 창은 움직이는 동안만 자주 살핍니다(X11은 창의 이동 소식을 받아 따라가고, Windows와 macOS는 움직이면 짧게, 잠잠하면 길게 쉽니다). Linux에서 마우스가 클로에게서 멀리 있으면 마우스 확인도 드물게 합니다.

`node scripts/bench.mjs`로 상태별 CPU 사용량과 문맥 전환 횟수를, `node scripts/frames.mjs`로 화면 합성 프레임 수를 잴 수 있습니다(Linux, 가상 화면). 실제 배터리 사용 시간 측정은 아니며, 전력 소모와 절감 폭은 운영체제, 그래픽, 창 관리자와 사용 방식에 따라 달라집니다.

## 고정 모드

설정 → 고정에서 켭니다. 자리가 고정되고 클릭은 클로를 통과합니다. 고정 중에도 대화하기와 쓰다듬기를 각각 허용할 수 있습니다. 고정 상태는 설정과 우클릭 메뉴에서 확인하며 캐릭터 위에는 잠금 안내를 덧씌우지 않습니다.

고정을 끄는 방법:

1. 선택한 앱을 쓰는 중 클로 위에 마우스를 잠깐 올렸다가 오른쪽 클릭
2. 트레이 또는 메뉴 막대 아이콘의 메뉴
3. 클로를 한 번 더 실행해 설정 창 열기
4. 터미널에서 `clau --unlock`

설정 → 실행 → 아이콘에서는 트레이 아이콘과 작업 표시줄 아이콘을 바꿀 수 있습니다. macOS에서는 메뉴 막대와 Dock 아이콘에 해당합니다. 둘 다 숨겨도 클로를 다시 실행하면 설정을 열 수 있습니다.

## Claude Code 따라 하기

설정 → 반응 → **Claude Code 따라 하기**를 켜면 새로 여는 Claude Code 세션부터 표정을 따라 합니다. 켜는 순간 Claude Code와 연결까지 하므로 따로 누를 것이 없습니다. 끄면 따라 하지 않습니다(`/clau` 명령은 남습니다).

- 생각할 때는 눈을 감는 표정과 눈동자를 위로 올리고 ㄱ 모양으로 입을 삐죽 내민 표정이 무작위로 나옵니다. 말할 때 입을 움직이고, 도구를 쓸 때 작은 친구가 움직입니다.
- 사용 제한에 걸리면 풀릴 때까지 잡니다.
- 일을 다 끝내면 "작업을 다 끝냈어요!", 사용 한도에 닿으면 "나 한도에 도달했어요.." 하고 말풍선으로 알려 줍니다(**작업 알림 말풍선**).
- 권한 허락, 선택지 질문, 계획 승인처럼 직접 골라야 할 때는 말풍선에 선택지를 띄우고, 클로에서 고른 답을 그대로 Claude Code에 전달합니다(**클로에서 바로 고르기**). 권한은 허락 / 다음부터 묻지 않기 / 거절, 질문은 보기 고르기·여러 개 고르기·직접 쓰기를 할 수 있습니다.
- 말풍선의 **Claude Code에서 고를래요**를 누르거나, 클로가 화면에 안 보이거나, 3분 동안 고르지 않으면 Claude Code가 늘 하던 대로 직접 묻습니다. 클로가 기다리는 동안에는 Claude Code 쪽 질문 창이 뜨지 않습니다.
- 선택을 기다리다 클로가 숨거나 연동·고르기 설정을 끄면 대기 중인 질문을 즉시 Claude Code로 돌려줍니다. 승인 전에 긴 명령·작업 폴더·파일 경로·변경 내용·계속 허용할 범위를 전부 스크롤해 확인할 수 있습니다. 계획 전문이 전달되지 않은 경우에는 Claude Code에서 확인합니다.
- `/clau`, `/clau settings`, `/clau unlock`, `/clau quit`을 사용할 수 있습니다.
- **Claude Code를 열 때**를 켜면 세션을 열 때 같이 깨어납니다.

이 연결은 말풍선의 대화 서비스 선택과 별개입니다. Codex로 대화할 때도 Claude Code 상태 연동을 따로 사용할 수 있습니다. Codex 대화 지원은 CLI로 답변을 받는 기능이며 Codex 작업 상태를 따라 하는 연동은 포함하지 않습니다.

연결하면 `~/.claude/clau/mod`에 mod를 놓고 `~/.claude/settings.json`의 `CLAUDE_CODE_PLUGIN_DIRS`에 경로를 추가합니다. 알림과 선택지는 이 컴퓨터 안(127.0.0.1)에서만 열리는 작은 창구로 오가며, 창구 번호와 열쇠는 나만 읽을 수 있는 `~/.claude/clau/app.json`에 적어 둡니다. 설정 → 실행 → Claude Code의 **연결 끊기**를 누르면 연동을 완전히 제거합니다. 함수형 훅(mod)을 지원하는 Claude Code가 필요합니다.

## 대화와 개인정보

질문과 대화 기억은 켜 둔 로컬 CLI에 전달되며, CLI가 로그인한 서비스로 보내 답을 받습니다. Groq를 켜 두면 차례가 왔을 때 Groq API로 보냅니다. Groq 키는 OS 보안 저장소에 암호화해 두고 일반 설정 파일에는 쓰지 않습니다. 서비스 이용과 사용량은 해당 CLI의 계정과 인증 방식에 따릅니다.

클로의 대화 기억은 실행 중 메모리에만 있으며 재시작하거나 **지금까지 나눈 대화 → 지우기**를 누르면 사라집니다. 두 CLI 모두 대화 세션을 저장하지 않는 옵션으로 실행합니다. Codex는 별도 임시 폴더와 읽기 전용 모드를 사용하고, 대화 실행의 명령 도구·훅·플러그인·연결 앱을 끕니다. 서비스 측 데이터 처리는 선택한 제공자의 정책을 따릅니다.

## 명령줄

```text
clau              켜기. 이미 떠 있으면 설정 창
clau --settings   설정 창과 함께 켜기
clau --unlock     고정 모드 끄기
clau --update     새 버전이 있으면 받아서 바꾸기
clau --quit       끄기
clau --cleanup    지우기 전 정리(Claude Code 연결, 자동 실행, ~/.claude/clau)
```

## 소스에서 실행·검증·빌드

Node.js와 npm이 필요합니다.

```bash
npm install
npm start            # Electron 앱 실행
npm test             # 채팅, 설정, 앱 식별자, 물리·효과음, SVG 모핑·창 수명 검사
npm run test:ui      # 임시 프로필에서 별도 대화 창과 캐릭터 위치 고정 검사
npm run build        # dist/에 Linux, Windows, macOS(Apple Silicon·Intel) zip과 latest.json
npm run build:linux  # 하나만: build:linux | build:win | build:mac
```

Linux의 UI 검사는 `xvfb-run`이 필요합니다(예: Ubuntu/Debian의 `xvfb` 패키지). UI 검사 실행기는 Linux와 macOS용이며 Windows에서는 단위 검사를 사용할 수 있습니다. 검사는 가짜 CLI 응답을 사용하므로 실제 유료 모델 요청을 보내지 않습니다. 자동 검사 통과와 각 운영체제의 실제 창 추적·권한·설치 검증은 별개입니다.

그림을 바꾸려면 모든 레이어를 `Main.png`와 같은 크기의 캔버스에 맞춰 그린 뒤 실행하세요.

```bash
python3 scripts/build-assets.py /그림/폴더 --px 900
```

레이어 이름과 역할은 `scripts/build-assets.py` 위쪽의 `LAYERS` 표에 있습니다. 뜬 눈 그림을 바꾸면 `python3 scripts/split-eyes.py`로 흰자·눈동자·눈꺼풀 세 장(마우스 따라보기용)을 다시 만드세요. X자 눈은 렌더러에서 두 눈을 각각 그려 크기에 상관없이 선명하게 표시합니다.

### 새 버전 내기

`package.json`의 `version`을 올리고 `CHANGELOG.md` 맨 위에 바뀐 점을 적어 main에 올리면, GitHub Actions가 검사와 빌드를 거쳐 그 버전의 릴리스를 만들고 zip과 `latest.json`을 올립니다. 설치된 클로들은 `latest.json`을 보고 새 버전을 알아챕니다.
